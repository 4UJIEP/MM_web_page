# Веб-приложение для Малого Матфака при ОмГУ

## 📖 Описание проекта

**Малый Матфак** — это веб-сайт профориентационной школы при **Омском государственном университете (ОмГУ)**.  
Платформа предназначена для учеников, родителей, преподавателей и администраторов, обеспечивая удобный доступ к информации и инструментам взаимодействия внутри школы.

### 🎓 Основной функционал

- 👨‍🎓 **Ученики и родители**  
  - Запись в учебные группы  
  - Просмотр журнала посещаемости и успеваемости  

- 👩‍🏫 **Преподаватели**  
  - Просмотр своих групп  
  - Редактирование журналов посещаемости и оценок  

- 🧩 **Администраторы/Методисты**  
  - Создание и редактирование групп  
  - Управление пользователями  
  - Полный контроль над содержимым сайта  

Кроме интерактивной части, сайт содержит общую информацию о школе:
- Список преподавателей  
- Учебные направления (математика, информатика, шахматы, куборо)  
- Новости и события школы

## ⚙️ Требования к окружению

Перед началом работы убедитесь, что установлены:

1. **Node.js 20.x**  
   Скачать можно с [официального сайта Node.js](https://nodejs.org/)

2. **Yarn**  
   Установите через npm:
   ```bash
   npm install -g yarn
   ```

## 🚀 Установка и запуск проекта

1. **Клонировать репозиторий**
   ```bash
   git clone https://github.com/<username>/<repository-name>.git
   cd <repository-name>
   ```

2. **Установить зависимости**
   ```bash
   yarn install
   ```

3. **Создать файл окружения**
   В корне проекта создайте файл `.env` и добавьте переменные окружения, например:
   ```bash
   API_URL=https://api.maly-matfak.ru
   ```
> 💡 *Будет использоваться позже при разработке*

4. **Запустить проект в режиме разработки**
   ```bash
   yarn dev
   ```
   После запуска проект будет доступен по адресу, написанному в консоли, например:
   ```
   http://localhost:5173
   ```

5. **Собрать проект для продакшена**
   ```bash
   yarn build
   ```

6. **Запустить собранную версию (опционально)**
   ```bash
   yarn preview
   ```

```
  /api             — функции для работы с сервером
  main.tsx         — точка входа приложения
  App.tsx          — корневой компонент
```
